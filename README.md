# ClanCells Simple Tools V6.5

Herramienta de servicio para Android: ADB, Fastboot, FRP, IMEI y MediaTek (MTK).

## Descarga

La version mas reciente esta en [Releases](https://github.com/Jonayo/clancells-simple-tools/releases/latest).

- Instalador oficial: `ClanCells-Simple-Tools-V6.5-setup.exe`
- Instala en `C:\ClanCells`
- El actualizador de la propia tool consulta este repositorio una vez al abrir.

> En este repositorio **no se publica codigo fuente**. Solo el instalador y el
> `version.json` que usa el actualizador.
